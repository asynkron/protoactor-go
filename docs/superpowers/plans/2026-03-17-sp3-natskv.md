# Sub-project 3: Integrate Shared Placement Actor into natskv IdentityLookup

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the natskv `IdentityLookup` to use the shared placement actor and activator proxy from Sub-project 1c. This replaces the direct `spawnActivation` method with placement actor-mediated spawning, adds stale member validation, duplicate-request coalescing, and member strategy selection. The existing client activation via NATS request/reply (`handleActivationRequest`, `requestRemoteActivation`) and the concurrency semaphore are preserved.

**Architecture:** `Setup()` spawns `$placement-activator` and `$proxy-activator` with natskv-specific persistence callbacks that capture the NATS KV lock revision in a closure. `Get()` gains stale member validation, duplicate-request coalescing, strategy-based member selection, and sends `ActivationRequest` to the local or remote placement actor. `Shutdown()` stops the placement actor and proxy before calling `removeMemberID`. The `spawnActivation` method and `ErrNameExists` recovery path are removed entirely.

**Tech Stack:** Go 1.21+, testify, embedded NATS server for unit tests, existing `cluster` package types (`PlacementConfig`, `NewPlacementActorProps`, `NewActivatorProxyProps`, `NewStrategyManager`, `ValidateActivationMember`, `ErrLockNotHeld`, `ActivatorStrategy`)

- [ ] **Step 9: Implement Setup() with placement actor and proxy spawning**

Edit `cluster/clusterproviders/natskv/natskv_identity.go`. Replace the `Setup` method. The key change is that after all existing setup logic, non-client members spawn the placement actor and proxy. The `PersistActivation` callback is a closure that captures the lock revision from the NATS KV `storeActivation` flow.

Note: The placement actor's `PersistActivation` callback receives the `requestID` (which is the `lockID`) as a parameter. The `revision` from `tryAcquireLock` is stored in a `sync.Map` keyed by `lockID` before sending the `ActivationRequest`. The callback looks up the revision by `requestID`, performs a CAS `Update` with that revision, then removes the entry from the map. If the CAS fails (revision mismatch, meaning the lock was stolen), `ErrLockNotHeld` is returned so the placement actor does not retry.

Replace the `Setup` method entirely:

```go
// Setup initializes the identity lookup with the cluster context, creates the
// required KV buckets, subscribes to topology events for member cleanup,
// and (on non-client members) spawns the placement actor and proxy.
func (il *IdentityLookup) Setup(c *cluster.Cluster, kinds []string, isClient bool) {
	il.cluster = c
	il.memberID = fmt.Sprintf("%s_%s", c.Config.Name, c.ActorSystem.ID)
	il.isClient = isClient
	il.inflights = make(map[string]*inflight)

	ctx := context.Background()
	js := il.provider.js
	clusterName := c.Config.Name

	// Create the identities KV bucket (no TTL -- activations persist).
	identities, err := js.CreateOrUpdateKeyValue(ctx, jetstream.KeyValueConfig{
		Bucket:   il.config.identityBucketName(clusterName),
		Replicas: il.config.Replicas,
	})
	if err != nil {
		il.setupErr = fmt.Errorf("natskv identity setup failed: create identities bucket: %w", err)
		slog.Error("natskv identity: failed to create identities bucket",
			slog.Any("error", err))
		return
	}
	il.identities = identities

	// Create the member tracking KV bucket.
	tracker, err := js.CreateOrUpdateKeyValue(ctx, jetstream.KeyValueConfig{
		Bucket:   "protoactor_" + clusterName + "_identities_tracking",
		Replicas: il.config.Replicas,
	})
	if err != nil {
		il.setupErr = fmt.Errorf("natskv identity setup failed: create tracking bucket: %w", err)
		slog.Error("natskv identity: failed to create tracking bucket",
			slog.Any("error", err))
		return
	}
	il.memberTracker = tracker

	// Subscribe to ClusterTopology events to clean up when members leave.
	c.ActorSystem.EventStream.Subscribe(func(evt any) {
		if topology, ok := evt.(*cluster.ClusterTopology); ok {
			for _, member := range topology.Left {
				il.removeMemberID(context.Background(), member.Id)
			}
		}
	})

	// Members subscribe to activation requests from cluster clients.
	// Clients cannot spawn actors, so they publish NATS requests that
	// members handle by performing the full Get() (spawn) protocol.
	if !isClient && il.provider.nc != nil {
		subject := activateSubject(c.Config.Name)
		queueGroup := c.Config.Name + "_activators"
		sub, err := il.provider.nc.QueueSubscribe(subject, queueGroup, il.handleActivationRequest)
		if err != nil {
			slog.Error("natskv identity: failed to subscribe to activation requests",
				slog.Any("error", err))
		} else {
			il.activationSub = sub
		}
	}

	// Non-client members: spawn placement actor and proxy.
	if !isClient {
		il.setupPlacementActor(c)
	}
}

// setupPlacementActor spawns the shared placement actor and activator proxy
// on non-client members. The placement actor uses natskv-specific persistence
// callbacks that write to the NATS KV identities bucket.
func (il *IdentityLookup) setupPlacementActor(c *cluster.Cluster) {
	// Create strategy manager for member selection.
	il.strategyMgr = cluster.NewStrategyManager(c)

	// Subscribe to topology events for strategy updates.
	c.ActorSystem.EventStream.Subscribe(func(evt any) {
		if topology, ok := evt.(*cluster.ClusterTopology); ok {
			for _, member := range topology.Left {
				il.strategyMgr.RemoveMember(member)
			}
			for _, member := range topology.Joined {
				il.strategyMgr.AddMember(member)
			}
		}
	})

	// Build persistence callbacks.
	//
	// PersistActivation: After the placement actor spawns a grain, it calls
	// this to store the activation in NATS KV. We use CAS Update with the
	// lock revision to ensure the lock is still held. The revision was stored
	// in il.lockRevisions (a sync.Map) by activateViaPlacement before sending
	// the ActivationRequest. The requestID parameter is the lockID, used as
	// the key into il.lockRevisions.
	//
	// If the CAS update fails because the revision changed (lock stolen by
	// another node or TTL expiry), we return ErrLockNotHeld so the placement
	// actor does not retry.
	persistActivation := func(ctx context.Context, ci *cluster.ClusterIdentity, pid *actor.PID, requestID string) error {
		key := kvKey(ci)

		// Retrieve and consume the revision stored by activateViaPlacement.
		revVal, ok := il.lockRevisions.LoadAndDelete(requestID)
		if !ok {
			// No revision stored -- cannot safely CAS. Treat as lock stolen.
			return cluster.ErrLockNotHeld
		}
		rev := revVal.(uint64)

		updated := activationRecord{
			LockID:     "", // Clear the lock.
			PidID:      pid.Id,
			PidAddress: pid.Address,
			MemberID:   il.memberID,
		}
		data, err := json.Marshal(&updated)
		if err != nil {
			return err
		}

		if _, err = il.identities.Update(ctx, key, data, rev); err != nil {
			// Revision mismatch: lock was stolen or TTL expired.
			return cluster.ErrLockNotHeld
		}

		// Track this identity key under the member.
		il.addKeyToMember(ctx, il.memberID, key)
		return nil
	}

	// RemoveActivation: When a grain terminates, the placement actor calls
	// this to clean the NATS KV record and member tracking entry.
	removeActivation := func(ctx context.Context, ci *cluster.ClusterIdentity, pid *actor.PID) error {
		key := kvKey(ci)

		// Read the entry to validate the PID before deleting.
		entry, err := il.identities.Get(ctx, key)
		if err != nil {
			if errors.Is(err, jetstream.ErrKeyNotFound) {
				return nil // Already gone.
			}
			return err
		}

		var rec activationRecord
		if err := json.Unmarshal(entry.Value(), &rec); err != nil {
			return err
		}

		// Only delete if the stored PID matches the terminating one.
		if rec.PidID != pid.Id || rec.PidAddress != pid.Address {
			return nil
		}

		if rec.MemberID != "" {
			il.removeKeyFromMember(ctx, rec.MemberID, key)
		}

		if err := il.identities.Delete(ctx, key, jetstream.LastRevision(entry.Revision())); err != nil {
			if !errors.Is(err, jetstream.ErrKeyNotFound) && !errors.Is(err, jetstream.ErrKeyExists) {
				return err
			}
		}
		return nil
	}

	placementCfg := cluster.PlacementConfig{
		PersistActivation: persistActivation,
		RemoveActivation:  removeActivation,
	}
	placementProps := cluster.NewPlacementActorProps(c, placementCfg)
	var err error
	il.placementPID, err = c.ActorSystem.Root.SpawnNamed(placementProps, "$placement-activator")
	if err != nil {
		slog.Error("natskv identity: failed to spawn placement actor", slog.Any("error", err))
		il.setupErr = fmt.Errorf("natskv identity setup failed: spawn placement actor: %w", err)
		return
	}

	// Spawn activator proxy.
	proxyProps := cluster.NewActivatorProxyProps(il.placementPID, il)
	il.proxyPID, err = c.ActorSystem.Root.SpawnNamed(proxyProps, "$proxy-activator")
	if err != nil {
		slog.Error("natskv identity: failed to spawn activator proxy", slog.Any("error", err))
		il.setupErr = fmt.Errorf("natskv identity setup failed: spawn proxy activator: %w", err)
		return
	}
}
```

```go
// Get resolves a cluster identity to an actor PID.
//
// The resolution protocol:
//  1. Check for an existing activation (validate member alive).
//  2. Check coalescing map -- wait if another request is in flight.
//  3. If client, request remote activation from a member via NATS.
//  4. Try to acquire a spawn lock.
//  5. Select target member via strategy.
//  6. Send ActivationRequest to placement actor (local or remote).
//  7. Return PID from ActivationResponse.
func (il *IdentityLookup) Get(ci *cluster.ClusterIdentity) *actor.PID {
	if il.setupErr != nil {
		slog.Error("natskv identity: cannot Get, setup failed", slog.Any("error", il.setupErr))
		return nil
	}
	il.acquire()
	defer il.release()

	ctx := context.Background()
	key := ci.AsKey()

	// Step 1: Check for existing activation with stale member validation.
	rec := il.getExistingActivation(ctx, ci)
	if rec != nil {
		if il.cluster != nil && il.cluster.MemberList != nil && rec.MemberID != "" {
			if cluster.ValidateActivationMember(il.cluster.MemberList, rec.MemberID) {
				return pidFromRecord(rec)
			}
			// Stale activation -- clean up and continue to re-activate.
			// removeMemberID deletes ALL activations for the stale member
			// (not just this one). This is intentional: if the member is
			// gone, all its activations are invalid. This matches the
			// topology event handler behavior (member departure triggers
			// full member cleanup).
			slog.Info("natskv identity: stale activation detected, cleaning up",
				slog.String("kind", ci.Kind),
				slog.String("identity", ci.Identity),
				slog.String("staleMemberID", rec.MemberID))
			il.removeMemberID(ctx, rec.MemberID)
		} else {
			// No member list available or no member ID -- return as-is.
			return pidFromRecord(rec)
		}
	}

	// Step 2: Check coalescing map.
	il.inflightMu.Lock()
	if inf, ok := il.inflights[key]; ok {
		// Another request is already in flight -- wait for it.
		il.inflightMu.Unlock()
		<-inf.done
		return inf.pid
	}

	// We are the first caller -- create the inflight entry.
	inf := &inflight{done: make(chan struct{})}
	il.inflights[key] = inf
	il.inflightMu.Unlock()

	// Ensure cleanup: remove from map and close channel on exit.
	defer func() {
		if r := recover(); r != nil {
			inf.err = fmt.Errorf("natskv identity: Get panicked: %v", r)
			slog.Error("natskv identity: Get panicked", slog.Any("panic", r))
		}
		il.inflightMu.Lock()
		delete(il.inflights, key)
		il.inflightMu.Unlock()
		close(inf.done)
	}()

	// Step 3: If client, request remote activation from a member via NATS.
	if il.isClient {
		rec = il.requestRemoteActivation(ctx, ci)
		if rec != nil {
			pid := pidFromRecord(rec)
			inf.pid = pid
			return pid
		}
		return nil
	}

	// Step 4: Try to acquire the spawn lock.
	lockID, revision, ok := il.tryAcquireLock(ctx, ci)
	if !ok {
		// Another node is spawning. Wait for it.
		rec = il.waitForActivation(ctx, ci)
		if rec != nil {
			pid := pidFromRecord(rec)
			inf.pid = pid
			return pid
		}
		return nil
	}

	// Step 5-6: Select target member and send ActivationRequest.
	pid := il.activateViaPlacement(ctx, ci, lockID, revision)
	if pid == nil {
		// Activation failed. Do NOT delete the lock key -- let the lock TTL
		// expire naturally. Deleting blindly could remove a valid activation
		// if a remote node won the race or the placement actor persisted
		// successfully but we timed out waiting for the response.
		return nil
	}

	inf.pid = pid

	// Populate the local PID cache.
	il.cluster.PidCache.Set(ci.Identity, ci.Kind, pid)

	return pid
}

// activateViaPlacement sends an ActivationRequest to the appropriate
// placement actor (local or remote) based on the strategy selection.
// The lockID is set as RequestId so the placement actor passes it through
// to the PersistActivation callback. The revision is stored in
// il.lockRevisions keyed by lockID so the PersistActivation callback can
// perform a CAS Update with the exact revision from tryAcquireLock.
func (il *IdentityLookup) activateViaPlacement(ctx context.Context, ci *cluster.ClusterIdentity, lockID string, revision uint64) *actor.PID {
	localAddress := il.cluster.ActorSystem.Address()
	var targetPID *actor.PID

	if il.strategyMgr != nil {
		targetMember := il.strategyMgr.GetActivator(ci, localAddress)
		if targetMember == nil {
			slog.Warn("natskv identity: no suitable member for activation",
				slog.String("kind", ci.Kind),
				slog.String("identity", ci.Identity))
			return nil
		}

		targetAddress := targetMember.Address()
		if targetAddress == localAddress {
			// Local -- send to our placement actor.
			targetPID = il.placementPID
		} else {
			// Remote -- send to target's proxy activator.
			// NOTE: for remote placement, the PersistActivation callback runs
			// on the remote node, so the revision cannot be passed via
			// il.lockRevisions. For remote activation, the lock TTL provides
			// safety; the remote node's callback will return ErrLockNotHeld if
			// the key revision has changed. Local activation is the common path.
			targetPID = actor.NewPID(targetAddress, "$proxy-activator")
		}
	} else {
		// No strategy manager -- fall back to local placement actor.
		targetPID = il.placementPID
	}

	if targetPID == nil {
		slog.Error("natskv identity: no target PID for activation")
		return nil
	}

	// Store the revision so PersistActivation can perform a CAS Update.
	// Only meaningful for local activation; cleaned up by the callback or
	// on failure below.
	il.lockRevisions.Store(lockID, revision)

	req := &cluster.ActivationRequest{
		ClusterIdentity: ci,
		RequestId:       lockID,
	}

	future := il.cluster.ActorSystem.Root.RequestFuture(targetPID, req, 10*time.Second)
	res, err := future.Result()
	if err != nil {
		// Clean up the stored revision -- PersistActivation will not be called.
		il.lockRevisions.Delete(lockID)
		slog.Error("natskv identity: activation request failed",
			slog.String("kind", ci.Kind),
			slog.String("identity", ci.Identity),
			slog.Any("error", err))
		// Do NOT delete the lock key here. Let the lock TTL expire naturally.
		// Deleting blindly could remove a valid activation written by another
		// node racing to acquire the same key.
		return nil
	}

	resp, ok := res.(*cluster.ActivationResponse)
	if !ok {
		il.lockRevisions.Delete(lockID)
		slog.Error("natskv identity: unexpected response type",
			slog.String("kind", ci.Kind),
			slog.Any("type", res))
		return nil
	}

	if resp.Failed || resp.InvalidIdentity {
		il.lockRevisions.Delete(lockID)
		slog.Warn("natskv identity: activation rejected",
			slog.String("kind", ci.Kind),
			slog.String("identity", ci.Identity),
			slog.Bool("failed", resp.Failed),
			slog.Bool("invalidIdentity", resp.InvalidIdentity))
		return nil
	}

	return resp.Pid
}
```

```go
// Shutdown performs cleanup when the cluster is shutting down.
// It stops the placement actor (which gracefully poisons all local grains),
// then the proxy activator, then closes strategies, unsubscribes from
// NATS activation requests, and finally removes member records from storage.
func (il *IdentityLookup) Shutdown() {
	// Stop placement actor first -- this triggers graceful shutdown of all
	// locally tracked grains (poisons them with DeactivationReasonShutdown).
	if il.placementPID != nil {
		if err := il.cluster.ActorSystem.Root.PoisonFuture(il.placementPID).Wait(); err != nil {
			slog.Error("natskv identity: failed to stop placement actor",
				slog.Any("error", err))
		}
		il.placementPID = nil
	}

	// Stop proxy activator.
	if il.proxyPID != nil {
		if err := il.cluster.ActorSystem.Root.PoisonFuture(il.proxyPID).Wait(); err != nil {
			slog.Error("natskv identity: failed to stop proxy activator",
				slog.Any("error", err))
		}
		il.proxyPID = nil
	}

	// Close strategy manager.
	if il.strategyMgr != nil {
		il.strategyMgr.Close()
		il.strategyMgr = nil
	}

	// Unsubscribe from NATS activation requests.
	if il.activationSub != nil {
		_ = il.activationSub.Unsubscribe()
		il.activationSub = nil
	}

	if il.setupErr != nil {
		return
	}

	// Remove all activations belonging to this member from storage.
	if il.memberID != "" {
		il.removeMemberID(context.Background(), il.memberID)
	}
}
```

## Key Design Decisions

1. **PersistActivation uses CAS `Update` with lock revision**: The `PersistActivation` callback performs a CAS `Update` using the revision obtained from `tryAcquireLock`. This preserves the same safety guarantee as the old `spawnActivation` path: if the lock was stolen (key deleted or overwritten between lock acquisition and persistence), the `Update` fails with a revision mismatch and `ErrLockNotHeld` is returned. The revision is stored in `il.lockRevisions` (a `sync.Map`) by `activateViaPlacement` before sending the `ActivationRequest`, keyed by `lockID`. The callback receives `lockID` as `requestID` and uses `LoadAndDelete` to retrieve the revision.

2. **Lock revision is passed via `lockRevisions` map**: The placement actor passes `RequestId` (the `lockID`) through to `PersistActivation` as the `requestID` parameter. This decouples the placement actor from NATS KV internals while enabling the callback to retrieve the corresponding revision. For remote activation (via proxy), the revision map is not applicable since the callback runs on the remote node; in that case, the callback's `LoadAndDelete` will find no entry and return `ErrLockNotHeld`, which is acceptable -- remote activation is handled by the remote node's own `Get()` → `tryAcquireLock` → `activateViaPlacement` flow.

3. **Semaphore is preserved**: The concurrency-limiting semaphore (`il.acquire()`/`il.release()`) is kept in the new `Get()`. It limits the number of concurrent activation attempts, which is still valuable even with coalescing (coalescing only helps for the same identity, the semaphore limits total concurrency).

4. **Client NATS request/reply preserved**: The `handleActivationRequest`/`requestRemoteActivation` path for cluster clients is unchanged. Clients still use NATS request/reply to ask a member to activate. The member's `Get()` (called from `handleActivationRequest`) now uses the placement actor internally.

5. **Existing liveness guard in RemovePid stays**: Per the spec, the liveness guard in `RemovePid` is defense-in-depth and is not removed. The placement actor prevents the class of bugs that required the guard, but keeping it is cheap insurance.

6. **Stale member validation uses MemberList**: The new `Get()` checks `cluster.ValidateActivationMember(il.cluster.MemberList, rec.MemberID)` before returning an existing activation. If the member has departed, the stale records are cleaned up immediately via `removeMemberID`. This matches the .NET `ValidateAndMapToPid` pattern. The validation is skipped if `MemberList` is nil (e.g., in tests that create IdentityLookup without a full cluster).
